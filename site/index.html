Why Anode

The checks you want, without the annotations you don't.

Anode keeps Rust's ownership discipline but replaces lifetimes with lexically scoped borrows, so views can never escape. Every function can state what it touches, what it may do and what it promises — and the compiler holds it to that.

.{}

Partial field views

A function names the fields it may read or write. Callers keep using disjoint fields while it runs.

c: &mut Counter.{ mut value, step }
@

Compile-time effects

No heap, no I/O, provably finite loops — checked transitively through every call, including packages.

@effect(no_alloc, no_io, bounded)
⊢

Contracts

Pre- and postconditions run on every call in every build mode; anode verify samples them in RAM.

requires c.step > 0; ensures result > 0;
id

Generational arenas & SoA

Graphs and trees use handles that detect staleness; columnar vectors store one contiguous array per field.

pub arena Nodes(Node); pub soa vector Rows(Row);
⇉

Two native backends

Cranelift for fast builds; C through MSVC /O2 for releases, with optional AddressSanitizer.

anode run . anode build . --release

Compiler architecture

          
One checked IR, two code generators. Nothing is emitted until every check passes.

          

            
Frontendparse · modules · [dependencies] packages · capability manifests

            
↓

            
Checkertypes · ownership & moves · scoped borrows · field views · @effect · contracts

            
↓

            
Checked IRbounds, overflow and contract checks stay in; proven ones are removed

            
↓

            

              
Cranelift → COFFdefault · anode run, test, build

              
C → MSVC--release (/O2) · --sanitize (ASan) · --lib

            

            
↓

            
link.exe → native .exeWindows x64; optional cached objects (cache_mb)

            
anode verify (contracts in RAM)anode agent (JSON Lines)?? holes + --campaignanode-lspanode fmt

Get started

      
From zip to running binary in three steps.

      

        

          
Download & extract

          
Grab the SDK from Releases and extract it anywhere.

Install for your user

          
Adds bin\ to PATH and sets ANODE_HOME. -WhatIf previews; -Uninstall reverts.

          
powershell -ExecutionPolicy Bypass -File .\install.ps1

        

        

          
Create & run

          
New projects include AGENTS.md and CLAUDE.md.

          
anode new hello_anode
cd hello_anode
anode run .
