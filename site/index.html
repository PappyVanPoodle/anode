Release 1.3.0 · Windows x64

anode.an

a systems language built for speed

Anode compiles to native Windows executables. The syntax is close to Rust, with ownership and moves but no lifetime annotations. Functions can list the struct fields they use, the effects they must not have, and requires / ensures conditions, and the compiler checks them.

Download the SDK (.zip) Source on GitHub
anode new hello_anode

Requires Visual Studio 2022 Build Tools (C++) for linking.

How a program is built

          
    
            
  1. Parse the modules and the packages listed in Anode.toml.
    2. 
            
  2. Check types, ownership, borrows, field views, effects and capabilities. Nothing is generated if a check fails.
    3. 
            
  3. Generate code with Cranelift by default, or as C compiled by MSVC with --release (and AddressSanitizer with --sanitize).
    4. 
            
  4. Link with MSVC's link.exe into a Windows x64 executable.
    5.

Install

      
Install on Windows

      
Needs Windows 10 or 11 (x64) and Visual Studio 2022 Build Tools with the C++ workload.

      

        

          
1. Download

          
Get the SDK zip from Releases and extract it, for example to C:\Tools.

          
anode-1.3.0-windows-x64.zip

        

        

          
2. Run the installer

          
Adds bin\ to your user PATH and sets ANODE_HOME. No administrator rights. -Uninstall undoes it.

          
powershell -ExecutionPolicy Bypass -File .\install.ps1

        

        

          
3. Create a project

          
In a new terminal:

          
anode new hello_anode
cd hello_anode
anode run .

        

      

      

        
Or all at once in PowerShell


iwr https://github.com/PappyVanPoodle/anode/releases/latest/download/anode-1.3.0-windows-x64.zip -OutFile anode.zip
Expand-Archive anode.zip "$env:LOCALAPPDATA\Programs" -Force
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\Programs\anode-1.3.0-windows-x64\install.ps1"
