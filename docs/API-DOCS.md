# `csv_jsonl` API reference

csv_jsonl: RFC 4180-style CSV rows and JSON Lines field extraction.

CSV: fields split on ','; a field that starts with '"' is quoted, may
contain ',' and uses "" for a literal quote. A quote inside an unquoted
field is literal. One trailing CR is ignored. An empty line is one empty field.

JSONL: `extract_json_*` read top-level keys of one object per line; keys
inside nested objects or string values never match.

# `markdown` API reference

markdown: block scanner for document ingestion, stored column-wise.

Recognized blocks (one pass, bounded, no I/O):
  kind 1 heading     ATX `#`..`######`; level = marker count; span = title text
  kind 2 paragraph   consecutive plain lines; level = 0
  kind 3 code_fence  ``` or ~~~ (3+); span = body between fences; level = 0
  kind 4 list_item   `-`, `*`, `+`, `1.` or `1)` plus a space; level = indent / 2 + 1;
                     following plain lines continue the item
`start..end` are byte offsets into the source, so `slice(doc, start, end)`
returns the block text. Words are whitespace-separated runs; sentences end
at `.`, `!` or `?` before whitespace or the end (code fences count none).

# `glob_regex` API reference

glob_regex: allocation-free, bounded byte matchers.

glob_match syntax (whole-target match):
  *       any sequence, including empty and '/'
  ?       any single byte
  [a-z]   byte class with ranges; [!..] or [^..] negates; a leading ']' and a
          leading/trailing '-' are literal; an unclosed '[' is literal
  \x      literal x

find_subpattern syntax (first match offset, or -1):
  ^ at the start anchors to offset 0, $ at the end anchors to the target end,
  . matches any byte, \x is literal x, everything else is literal.
Index of the ']' closing the class opened at `p`, or -1.

# `json` API reference

json: strict JSON parser into a generational arena tree, queries and a
compact deterministic writer.

Supported values: null, true/false, 64-bit integers, strings with every
RFC 8259 escape (\u0000 is rejected because text cannot hold NUL), arrays
and objects. Fractions and exponents are rejected. Nesting depth <= 128.

Nodes are numbered in parse (pre-order) order, root = 0. Children form a
linked list through `first_child` / `next_sibling` (-1 = none); object
members carry their `key`. Arena handles have no integer form, so
`JsonDoc.ids[i]` holds the handle of node i.

# `bench` API reference

bench: order statistics over timing samples and deterministic Markdown/JSON
reports. Timing itself is I/O, so callers measure (for example with
`monotonic_ms()`) and hand this package the samples.

Each sample is the elapsed time in microseconds of one batch of
`iterations` runs. Percentiles use the nearest-rank method on a sorted
copy; an even sample count takes the lower-rounded mean of the two middle
values as the median.
